ClubEconomyControl es una aplicación ASP.NET Core siguiendo un patrón de diseño MVC, con el que podemos gestionar la economía
y la plantilla de clubes deportivos. Puedes visualizar sus jugadores, calcular amortizaciones, controlar tanto el balance como
el límite salarial del club y mostrar algunos detalles financieros del club. Puedes generar tantos clubs como desees.

• 	📋 Listado de jugadores por club con control de ventas y amortización restante.

• 	💰 Cálculo de amortización anual por jugador.

• 	📊 Cálculo del límite salarial disponible por club.

• 	🧮 Servicio de lógica financiera desacoplado ().

• 	🖥️ Vistas limpias que muestran datos sin lógica de negocio.

• 	🔐 Control de excepciones para datos faltantes o inconsistentes.
